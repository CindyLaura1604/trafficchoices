# Caminho Seguro — jogo React

## Copie para seu projeto
- `src/App.js` -> substitua seu `App.js`
- `src/App.css` -> substitua seu `App.css`
- `src/index.js` -> substitua seu `index.js`
- `src/data/levels.js` -> crie a pasta `src/data` e coloque o arquivo
- `public/assets` -> copie a pasta inteira para `public/assets`

## Cenários ainda não enviados
Substitua estes dois arquivos quando tiver os cenários definitivos:
- `public/assets/cenarios/trabalho.png`
- `public/assets/cenarios/casa.png`

O código já chama exatamente esses nomes.

## Controles
W A S D ou setas. Caminhe até os marcadores `!` para abrir as situações.

## Regras
5 vidas por nível. Cada erro tira 1 vida. Ao perder todas as vidas, o progresso da aventura reinicia. Cada acerto aumenta o progresso. Ao completar 100% de um nível, uma recompensa é desbloqueada.
